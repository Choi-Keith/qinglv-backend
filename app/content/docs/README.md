
分数计算公式: 参考[掘金的热度](https://juejin.cn/post/6844903833856901133)
- G为重力因子：[1.5, 1.8]， G越大，score越小，排序的刷新频率越快
- t  = time.now() - createdAt
- I 为新内容的初始质量分数，可以设置为10
- score = (W + I)/(t + 1)^G
## 话题分数计算 W
- 引用数量 + 5
  

## 帖子分数计算 W

- 点赞数 + 1
- 点踩数 - 1
- 收藏数 + 2
- 分享数 + 2
- 一级评论数 + 1

## 文章分数计算 W

- 点赞数 + 2
- 点踩数 - 2
- 收藏数 + 4
- 分享数 + 4
- 一级评论数 + 2

## 帖子或文章自动进入审核状态
- 点踩数 >= 5 and 点踩数 < 2 * 点赞数
如果审核通过，则保持原来的样子；如果审核不通过，则只能自己可见
